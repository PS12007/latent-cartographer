Take a walk where the model knows where it is. For each of the 64 cells, steer its belief to that cell and record which moves it now considers possible. Draw a wall wherever it refuses to go. The environment is never consulted; every line on the right comes from the network’s weights.

What is going on here

Each training sequence is a random walk through a fixed 8×8 maze, written as moves. One time in three the sequence opens with the start cell; otherwise it opens with ?, so the walker could be anywhere. The model is trained only to predict the next move. Doing that well requires knowing which moves are legal, which requires knowing where you are, which requires a map nobody gave it.

Because the walker picks uniformly among open directions, the best possible predictor is an exact Bayesian filter over the 64 cells. Fig. b compares that posterior with a 64-way linear readout of the model’s activations. When the start is unknown, the true posterior is often split across several distant cells, and the probe recovers that multi-modal shape, not just the most likely cell.

Steering tests whether the representation is used. Clicking a cell pushes the newest token’s residual vector along the probe’s direction for that cell. If the model consults this internal map, its next-move prediction should switch to the walls of the new cell, and after block 3 it does so about 90% of the time (random pushes of the same size: 4%). Do it for every cell and the whole maze can be redrawn from the model alone (Fig. e). One surprise: the edit does not carry over to the next step. The model rebuilds its location from the raw move history at every token instead of carrying it forward like a recurrent network. Full analysis in the repository.
