What is going on here

Each training sequence is a random walk through a fixed 8×8 maze, written as moves. One time in three the sequence opens with the start cell; otherwise it opens with ?, so the walker could be anywhere. The model is trained only to predict the next move. Doing that well requires knowing which moves are legal, which requires knowing where you are, which requires a map nobody gave it.

Because the walker picks uniformly among open directions, the best possible predictor is an exact Bayesian filter over the 64 cells. Fig. b compares that posterior with a 64-way linear readout of the model’s activations. When the start is unknown, the true posterior is often split across several distant cells, and the probe recovers that multi-modal shape, not just the most likely cell.

Steering tests whether the representation is used. Clicking a cell pushes the newest token’s residual vector along the probe’s direction for that cell. If the model consults this internal map, its next-move prediction should switch to the walls of the new cell, and after block 3 it does so about 90% of the time (random pushes of the same size: 4%). Do it for every cell and the whole maze can be redrawn from the model alone (Fig. f). One surprise: the edit does not carry over to the next step. The model rebuilds its location from the raw move history at every token instead of carrying it forward like a recurrent network. Full analysis in the repository.

Findings

Everything below comes from the same 0.8M-parameter model you just played with. Each claim is backed by a probe, an intervention, or both; code and numbers are in the repository.

1 · The belief is in the residual stream

A 64-way linear probe recovers the exact Bayesian posterior over cells with KL 0.10 nats, against 1.64 when decoding from the model’s own output. Displacement appears first (block 1); the belief sharpens with every later block.

2 · It is causal, and the maze can be read back out

Pushing the newest token’s activations along the probe direction for another cell makes the model expect that cell’s walls 90% of the time (random pushes: 4%). Doing this for every cell recovers all 112 interior walls. The edit does not persist to the next token: location is rebuilt from the history every step.

3 · It localises with an egocentric sketch

Blocks 2–3 hold a map of where the walker has been relative to itself: visited cells and walked passages. It peaks before the maze-frame position does. Writing one remembered passage into it moves the belief toward whichever candidate cell actually has that passage.

4 · The early map is a flat sheet shaped like the grid

Cell-average activations after block 1 lie on a 2-D sheet (85% of variance) that redraws the maze. Distances follow grid coordinates, not walking distance. By block 4 the same cells are regrouped by which walls they have, the format needed to choose a move.

5 · Heads divide the labour

One head (B1H1, uniform attention) is the move integrator; removing it ruins even known-start prediction. Nine heads, concentrated in blocks 2–3, matter almost only when the start is unknown. Try knocking them out in Fig. d.

6 · It replicates

Retrained from scratch on three more 8×8 mazes: every wall recovered each time, steering works 82–90%, and edits never persist. On a 12×12 maze with the same small model, 261 of 264 walls come back. The map also survives walking styles never seen in training (98.7% legal-move accuracy when lost).
