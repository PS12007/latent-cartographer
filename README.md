# Latent Cartographer

A tiny transformer reads nothing but move tokens (`N E S W`) from random walks through a hidden maze.
It is never shown the maze, a coordinate, or a wall. This project shows that it nonetheless builds an
internal map and a Bayesian belief over where it is, that the map can be steered causally, and that
the whole maze can be read back out of its activations.
